# 安克录音豆 D3200 协议摘要

本文只记录本插件用到的协议事实。逆向资料与浏览器实现分别来自两个公开参考项目，见根目录 README 的致谢；本仓库不包含它们的源代码。

## 发现与连接（CoreBluetooth）

| 项 | 值 |
|---|---|
| 服务 UUID | `020cf5da-0000-1000-8000-00805f9b34fb` |
| 写特征 | `00007777-0000-1000-8000-00805F9B34FB` |
| 通知特征 | `00008888-0000-1000-8000-00805F9B34FB` |

Host 的 Swift 助手用 `CBCentralManager` 按服务 UUID 扫描；macOS 上设备本地名可能为空，按服务 UUID 识别。

## 帧格式

手机 → 设备：

```
08 EE 00 00 00 | cmdType | cmdId | total_length u16 LE | payload | checksum
```

设备 → 手机：

```
09 FF 00 00 | status | cmdType | cmdId | total_length u16 LE | payload | checksum
```

- `checksum = sum(all preceding bytes) & 0xFF`
- `total_length` 含整帧
- 通知数据是任意分片，必须用 `PacketBuffer` 重新拼帧
- 最小帧 10 字节

## 本插件用到的命令

| 方向 | type/id | 用途 | payload |
|---|---|---|---|
| TX | `01/01` | 读设备信息 | 空 |
| TX | `18/82` | 开始 / 暂停录音 | `01` / `02` |
| TX | `1B/0E` | 读离线录音列表（含结束时间） | `page` u16 LE |
| TX | `1A/07` | 开始导出文件 | `transferred u32 LE` + `fileId u32 LE` + `realtime 0` |
| TX | `1A/10` | 删除文件 | `fileId u32 LE` |
| RX | `01/01` | 设备信息 | 见下 |
| RX | `01/03`、`01/04` | 电量 / 充电推送 | 2 字节 |
| RX | `18/82` | 录音状态 | 1 字节：0 停止 / 1 录音 / 2 暂停 |
| RX | `1B/0E` | 列表 | `count u16` + 每条 12 字节（fileId/endTime/size） |
| RX | `1A/07` | 文件头（含密钥材料） | 见解密 |
| RX | `1A/08`、`1A/12` | 文件分片 | 160 字节密文一段 |
| RX | `1A/0A` | 导出完成 | — |
| RX | `1A/10` | 删除结果 | status |
| TX/RX | `2E/01` | ECDH 会话握手 | 65 字节 P-256 公钥 |

## 解密

握手：

```
shared = ECDH(appPrivateKey, devicePublicKey)
sessionKey = HKDF-SHA256(shared, salt={1,2,3}, info={1,2,3}, 32)
```

文件头（payload 从 0 开始）：

```
0..3   fileId u32
4..7   size u32
8..23  nonce 16B
24..69 encryptedFileKey 46B
70..85 sessionNonce 16B
86     errorCode
```

```
plain = AES-CTR-256(sessionKey, counter=sessionNonce, encryptedFileKey)
plain[0..14) == "soundcored3200"
fileKey = plain[14..46)
```

分片：

```
counter = nonce[0..12) || BE_u32(sequence * 10)
plain = AES-CTR-256(fileKey, counter, ciphertext)
```

分片帧结构：从整帧偏移 9 开始，每 166 字节为 `seq u32 | flags u8 | 160B 密文 | 1B 填充`。

## 音频封装

解密后是裸 Opus 帧，需要封装为 Ogg/Opus：每帧 20 ms，采样率 16 kHz，单声道。参考实现 `oggOpus.js` 直接移植；浏览器再用 WebAudio 解码为 WAV 供不支持 Ogg 的 ASR 使用。

## 已知限制

- 同一录音豆不能同时被飞书 App 和网页稳定占用 BLE。
- 导出大文件必须保持页面在前台；单次导出超时按参考实现取 120 s。
- 原生桥当前仅 macOS；其他平台尚未提供 BLE 实现。
- 不在本插件实现：OTA、解绑、恢复出厂、Wi-Fi SoftAP 快速导出。
